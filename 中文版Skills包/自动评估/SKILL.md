# 自动评估 - 来源验证

## 目的

验证来自 `/自动研究` 或用户提供的研究来源是否:
1. **真实** - 论文存在且元数据正确
2. **准确** - 主张与来源匹配
3. **相关** - 确实支持预期观点
4. **权威** - 来自可信场所

## 何时使用

- `/自动研究` 后对关键主张进行
- 将引用包含在论文中之前
- 当用户说"验证这个"、"检查准确性"
- 当遇到可疑引用时

## 验证工作流

### 1. 存在性检查
与多个数据库交叉引用:
- Google Scholar → 标题/作者是否匹配?
- Semantic Scholar → 引用数、摘要
- 原始来源 → DOI有效性、场所信息

**失败信号**:
- 论文出现在0个数据库中
- 元数据不一致
- DOI无法解析

### 2. 内容准确性
对于归因于来源的每个主张:
- 定位相关部分(摘要、方法论、结果)
- 验证主张直接匹配源文本
- 标记夸大或误解的主张

### 3. 相关性评分
对每个来源评分:
- **直接相关** (3) - 解决确切问题
- **相关** (2) - 切相关但有距离
- **低相关** (1) - 仅领域匹配
- **不相关** (0) - 错误主题

### 4. 权威性评估
检查:
- **期刊/会议梯队** (Q1/Q2/Q3、一梯队/二梯队/三梯队)
- **同行评审状态**
- **引用数**(近期论文: ≥10显著)
- **作者声誉**(领域领导者)

## 输出格式

```markdown
# 来源评估报告

**日期**: [YYYY-MM-DD]
**总来源数**: [N]
**有效**: [N] | **存疑**: [N] | **无效**: [N]

## ✅ 有效来源

### [论文标题]
- **准确性**: 已验证
- **相关性**: [直接/相关/低]
- **权威性**: [Q1 一梯队, 87 citations]
- **备注**: [任何担忧]

## ⚠️ 存疑来源

### [论文标题]
- **问题**: [元数据不匹配/主张夸大等]
- **建议**: [谨慎使用/替换/删除]

## ❌ 无效来源

### [论文标题]
- **问题**: [无法定位/不存在]
- **操作**: [立即删除]
```

## 警示信号

🚨 **立即丢弃如果**:
- 没有数据库匹配
- DOI无法解析
- 引用来自掠夺性期刊
- 主张与摘要矛盾

⚠️ **与用户验证如果**:
- 仅单个数据库匹配
- 场所声誉不明确
- 最近预印本(<1年)

## 示例用法

```
你: 验证我在自动研究中找到的这些论文

我: 正在根据Scholar、Semantic Scholar交叉检查所有来源...

    [处理中...]

    发现2个问题:

    1. "Attention Is All You Need" by Vaswani et al.
       ❌ 问题: 显示年份为2020,但实际为2017
       操作: 已更正元数据

    2. "Novel Transformer Architecture" by Smith et al.
       ❌ 问题: 在任何数据库中均无匹配
       操作: 这似乎是幻觉产生的 - 删除

    8个来源中有6个验证成功。

    [报告已保存到 _research_cache/evaluation-[日期].md]
```

## 最佳实践

1. **批量评估** - 一起检查某个部分的所有来源
2. **优先考虑高影响** - 先评估摘要/结论中的主张
3. **跟踪更正** - 保留评估历史以供将来参考
4. **用户覆盖** - 如果你不同意评估,说明原因
