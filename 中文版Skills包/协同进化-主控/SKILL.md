# 协同进化主控制器

## 快速开始

通过初始化协同进化工作流开始任何学术写作任务:

```
/协同进化-主控
```

这将:
1. 加载协同进化方法论 (参见 [核心方法论.md](../../core_methodology.md))
2. 为当前阶段配置技能集
3. 指导你完成相应的工作流

## 核心理念

**人机协同进化**: 这不是关于AI替你写作。而是关于:
- 你设计规则和约束
- AI在约束内执行
- 双方迭代优化范式本身

**角色分工**:
- **人类**: 核心论点、关键论证、段落结构、最终决策
- **AI**: 学术表达、逻辑流畅度、语言润色、信息收集

## 工作流阶段

### 阶段1: 澄清 (质询我 + 质询你)
- `/质询我` - 让AI质询你的研究计划
- `/质询你` - 向AI提出澄清问题以优化上下文
- 目标: 执行前达成共同理解

### 阶段2: 研究 (自动研究 + 自动评估)
- `/自动研究` - 使用确定性工具收集学术来源
- `/自动评估` - 验证信息的准确性和相关性
- 目标: 高质量、经过验证的基础

### 阶段3: 写作 (写作助手)
- `/写作助手` - 人类主导,AI辅助写作
- 目标: 人类拥有权的共创内容

## 使用模式

**新论文**: 按顺序执行所有阶段
**已有工作**: 根据需要跳转到特定阶段
**迭代**: 重新进入任意阶段进行优化
