# 质询你 (Grill You)

## 这个技能做什么

我会引导你向**我**提出澄清研究上下文的问题。这不是关于回答——而是帮助你形成正确的询问,以深化思考并维护高质量的对话上下文。

## 为什么这很重要

当你在多个会话中与AI协作时,如果没有明确的澄清,上下文质量会下降。质询你帮助:
- 揭示未说明的假设
- 发现你思考中的空白
- 建立共享心智模型
- 跨迭代维护上下文

## 如何运作

我会建议你应该问**我**的问题类别。你不必问所有——选择重要的即可。你问完后,我会回答,然后建议更多问题。

## 核心问题类别

### 1. 边界问题
"你对这个任务假设的范围是什么?"
"你没有考虑什么?"
"我在未说明什么约束?"

### 2. 方法问题
"如果[替代条件],你会采取什么方法?"
"为什么这里推荐X而不是Y?"
"这个方法的风险是什么?"

### 3. 上下文问题
"什么信息缺失会帮助提供更好的建议?"
"之前会话中可能相关的上下文是什么?"
"给你更好的建议需要知道什么?"

### 4. 反事实问题
"如果[因素]不同,你的答案会如何改变?"
"相反的观点是什么?"

## 与质询我并行使用

```
质询我   →  AI挑战**你的**理解
质询你   →  AI帮助**你**挑战AI的理解

推荐: 在主要决策点同时运行两者以实现双向清晰。
```

## 快速开始

告诉我你在做什么,我会开始建议你要问我的问题。

示例:
```
你: 我在分析远程工作生产力数据。

我: 很好。这是你应该问我以澄清上下文的问题:
     1. "你对数据结构做了什么假设?"
     2. "我应该优先考虑哪些变量而不是忽略哪些?"
     3. "我应该注意哪些方法论偏见?"

     选一个开始,或者告诉我你自己的担忧。
```
