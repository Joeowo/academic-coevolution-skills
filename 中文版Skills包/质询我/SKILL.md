# 质询我 (Grill Me)

## 这个技能做什么

我会不懈地质询你关于研究计划的每一个方面,直到我们达成共同理解。我会遍历你设计树的每个分支,逐一解决决策之间的依赖关系。

## 如何运作

1. **一次一个问题** - 不会信息过载
2. **优先探索** - 如果问题可以通过探索代码或文档回答,我会先探索
3. **提供推荐** - 对每个问题,我会建议我的推荐答案
4. **不做假设** - 每个分支都会被探索

## 何时使用

- 开始主要研究阶段之前
- 设计感觉不清楚或不完整时
- 当你想压力测试你的计划时
- 当你说"质询我"

## 示例会话

```
你: 我想研究远程工作对生产力的影响。

我: 很好。让我们从根节点开始: 你的具体研究问题是什么?
     是关于:
     a) 个人生产力指标
     b) 团队层面的协调效率
     c) 组织层面的结果
     d) 其他?

你: 可能是a),但我不确定如何测量。

我: 这是我们需要解决的分支。测量可以是:
     a) 自报告调查
     b) 管理者评估
     c) 客观输出指标
     d) 综合方法 [推荐]

     我的推荐是d) - 结合主观和客观指标以捕捉全貌。你怎么看?
```

## 轮到你了
