# Academic Coevolution Skills - 人机协同学术写作工具箱

> 核心理念: **不是AI替你写作,而是人机协同进化**

## 核心思想

这个工具箱基于人机协同进化的学术写作范式:

> "在整个写作过程中,我不是简单地'使用'AI,而是在AI的辅助下设计了一个系统性的协作范式,然后AI和我共同在这个范式内运作。"

**协作范式的核心**:
- 你设计规则和约束
- AI在约束内执行
- 通过迭代不断优化范式本身

**角色分工**:
- **人类**: 核心论点、关键论证、段落结构、最终决策
- **AI**: 学术表达、逻辑连接、语言润色、信息检索
- **双方交替**: 交互协作

## Skills 概览

### 主控技能

| Skill | 功能 | 使用场景 |
|-------|------|---------|
| `/academic-coevolution-main` | 工作流主控制器 | 开始学术写作任务、协调多个技能 |

### 核心技能

| Skill | 功能 | 使用场景 |
|-------|------|---------|
| `/grill-me` | 质询你的计划 | 压力测试方案、深度澄清想法 |
| `/grill-you` | 引导向AI提问 | 明确想法、维护高质量上下文 |
| `/auto-research` | 学术文献检索 | 查找论文、构建文献基础 |
| `/auto-evaluate` | 源验证评估 | 验证信息准确性、交叉检查 |
| `/academic-writing-assist` | 人机协同写作 | 写作助手、结构优化、表达改进 |

## 工作流程

### 完整流程

```
1. 启动
   ↓
   /academic-coevolution-main
   ↓
2. 澄清阶段 (并行执行)
   ├─ /grill-me  ←→  你 ←→  /grill-you
   └─ 目标: 达成共同理解
   ↓
3. 研究阶段 (顺序执行)
   ├─ /auto-research  (检索)
   └─ /auto-evaluate  (验证)
   ↓
4. 写作阶段 (迭代执行)
   └─ /academic-writing-assist
   ↓
5. 迭代优化
   (返回任意阶段)
```

### 分阶段说明

#### 阶段1: 澄清 (grill-me + grill-you)

**双向质询,达成共识**

- `/grill-me`: AI不断质询你的研究设计,暴露隐藏假设
- `/grill-you`: AI帮助你向AI提问,明确你想了解什么
- **并行使用效果最佳**: 双向澄清,消除理解偏差

#### 阶段2: 研究 (auto-research + auto-evaluate)

**确定性工具,零幻觉**

- `/auto-research`: 只使用确定性工具查询学术数据库
- `/auto-evaluate`: 交叉验证来源真实性
- **原则**: 禁止AI生成论文元数据,一切必须有来源

#### 阶段3: 写作 (academic-writing-assist)

**人主导,AI辅助**

- 你: 写核心内容、确定结构、关键论点
- AI: 优化表达、改进流畅度、学术风格
- **迭代**: 多轮协作,AI学习你的风格

## 快速开始

### 新论文流程

```bash
# 1. 启动工作流
/academic-coevolution-main

# 2. 澄清研究问题 (可选但推荐)
/grill-me      # 让AI质询你的计划
/grill-you     # 向AI提问明确想法

# 3. 收集文献
/auto-research "你的研究主题"
/auto-evaluate # 验证来源

# 4. 开始写作
/academic-writing-assist
```

### 场景化使用

```
场景: 深化研究问题
→ /grill-me

场景: 验证引用真实性
→ /auto-evaluate

场景: 改进段落表达
→ /academic-writing-assist "帮我优化这段话的学术表达"

场景: 构建文献基础
→ /auto-research
→ /auto-evaluate
```

## 设计原则

### 1. 人机协同,而非人机替代
- 你保留内容所有权
- AI承担表达优化
- 决策始终由你做出

### 2. 确定性优先,零幻觉承诺
- 文献检索只用确定性工具
- 禁止生成虚假来源
- 交叉验证所有关键信息

### 3. 迭代优化,共同进化
- 每一轮都改进范式本身
- AI学习你的意图和风格
- 你理解AI的能力和边界

### 4. 简洁高效,渐进增强
- 每个skill专注单一功能
- 可独立使用或组合使用
- 按需调用,不强制流程
